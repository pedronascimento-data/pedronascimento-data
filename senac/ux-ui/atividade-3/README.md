## Fluxos de navegação para avaliação

1. Na tela de **login**, clique **Entrar no sistema** → **Controle de caixa**.
2. Na tela de **login**, clique **Simular erro de login** → **Erro de autenticação** → **Tentar novamente**.
3. Em **Controle de caixa**, clique **Cadastro de clientes** para mudar de tela.
4. Em **Cadastro de clientes**, clique **Controle de caixa** para retornar.
5. Clique **Salvar lançamento** ou **Salvar cliente** para ver a mensagem de confirmação simulada.
6. Clique **Sair da conta** para retornar ao login.

## UX e UI

- Frames desktop de **1280 × 800**.
- Interfaces editáveis em Figma, não imagens completas importadas como screenshots.
- Navegação lateral consistente em caixa e clientes.
- Paleta de vinho, creme e branco, com fotografia gastronômica e hierarquia tipográfica.
- Campos rotulados e mensagens de erro legíveis.
- Feedback de conclusão dos cadastros e operações.

## Arquivos e histórico

- **Entrega corrigida:** o link Figma é a fonte oficial para testar interações.
- [`prototipo.html`](prototipo.html): **versão HTML anterior**, mantida como demonstração e histórico, mas **não substitui o projeto do Figma**.
- O pacote de entrega produzido na conversa contém quatro PNGs e um PDF de **reconstruções visuais de apoio**. Não são exportações literais do Figma, pois a conta Starter atingiu o limite de consultas durante a exportação. A versão atual e interativa deve ser consultada no link Figma.

**Limitação do protótipo:** as telas simulam navegação e confirmações; não há validação real de senha, consulta a banco de dados, persistência ou processamento de pagamentos. O Figma não salva os dados digitados como um aplicativo em produção.
