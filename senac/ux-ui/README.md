## Correções realizadas

### Atividade 1
- O formulário foi criado no **Google Forms**, com oito perguntas e as duas imagens dos wireframes originais.
- Foram registradas **oito respostas totalmente simuladas**, claramente identificadas como fictícias. Não são entrevistas reais.
- O **relatório oficial do SENAC** foi corrigido sem alterar seu modelo: duas personas, mapa de Maria Oliveira no próprio documento e mapa de Carlos Mendes como complemento.
- O link de participação foi incluído no relatório, e o script de atualização do formulário foi disponibilizado [nesta pasta](atividade-1/atualizar_formulario_com_imagens.gs).
- A execução confirmou **8 respostas preservadas** e **2 imagens incluídas**. A confirmação externa de acesso à pesquisa depende das permissões do Google Forms.

### Atividade 3
- Foram criados quatro frames desktop **nativos do Figma Design**, com campos, botões, imagem gastronômica e elementos editáveis.
- Foram adicionadas ligações de protótipo para login, erro de autenticação, caixa, cadastro de clientes, retorno e saída.
- As operações de salvamento demonstram janelas de confirmação.
- O link de apresentação foi compartilhado e **o usuário relatou que funcionou em janela anônima**, atendendo ao ponto central apontado pelo professor.
- O [arquivo HTML anterior](atividade-3/prototipo.html) foi mantido como demonstração histórica e **não substitui o Figma** para fins de avaliação.

## Observações sobre os arquivos de entrega

Os pacotes **DOCX, PDF, PNG e ZIP** corrigidos foram criados como arquivos de entrega no ChatGPT, mas **não foram transferidos como binários para o GitHub por esta integração**. Neste repositório estão as fontes textuais editáveis, os SVGs da Atividade 2, os scripts e os links públicos relevantes. Para baixar o pacote completo nos formatos solicitados pelo SENAC, utilizar os anexos originais da conversa.

**Aviso:** todos os personagens, números e resultados da Atividade 1 são simulados. O protótipo de pizzaria também é didático, sem integração a um banco de dados ou validação real de credenciais.
