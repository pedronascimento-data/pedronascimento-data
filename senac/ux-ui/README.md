# Atividades de UX/UI — SENAC

Projeto acadêmico de **experiência do usuário, pesquisa UX e prototipação de interfaces**, organizado em três atividades.

> **Observação:** os dados de pesquisa e os personagens da Atividade 1 são inteiramente simulados. Os protótipos não integram um sistema real, não persistem dados e são apenas demonstrativos.

## Atividades

| Etapa | Objetivo | Conteúdo |
|---|---|---|
| [Atividade 1](atividade-1/relatorio.md) | Pesquisa de UX para um sistema de cadastro de alimentos em refeitório | Questionário, resultados simulados, personas e mapa de empatia |
| [Atividade 2](atividade-2/README.md) | Wireframes desktop para a pizzaria do Sr. Manoel | Login, erro de autenticação, controle de caixa e cadastro de clientes |
| [Atividade 3](atividade-3/README.md) | Protótipo de alta fidelidade do sistema de pizzaria | Interfaces com identidade visual e navegação entre telas |

### Execução da Atividade 3
Baixe [o protótipo HTML](atividade-3/prototipo.html) e abra no navegador (o arquivo pode ser executado localmente). Acesso de demonstração: `admin` / `123456`. Qualquer combinação diferente simula a tela de erro.
